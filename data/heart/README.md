# UCI Heart Disease, processed collections

`processed.cleveland.data`, `processed.hungarian.data`, `processed.switzerland.data` and
`processed.va.data` are the four processed collections of the UCI Heart Disease data set
(Janosi, Steinbrunn, Pfisterer and Detrano, 1988; UCI Machine Learning Repository,
https://doi.org/10.24432/C52P4X), distributed under the Creative Commons Attribution 4.0
International licence. They are the input of the clinical-centre experiments
(`--stage hospitals`, Fed-Heart-Disease), one collection per client, and are kept here so
that those runs can be reproduced without a download.

Collection sizes: Cleveland 303, Hungary 294, Switzerland 123, Long Beach (VA) 200 patients.
